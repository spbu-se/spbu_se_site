# security-audit

Structured security audit: GitHub security surface (Dependabot/CodeQL/advisories) + three-pass code review (authz/CSRF/OAuth, XSS, SQLi/files) with verify-before-fix and dismissal-only-with-proof.
Not general code-quality audit (code-audit), doc health (docs-audit), or process analysis (retrospective-analysis).
Load on security review requests, before release/staging→current gates, or when triaging security alerts.
