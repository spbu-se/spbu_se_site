# Annual pre-admission checklist

Every year, **before the admission campaign starts** (typically May–June), the
following must be verified and updated. The repo-review skill should trigger
this checklist.

## Programs & admission

- [ ] **Bachelor/master program links** — `spbu.ru/sveden/education` for
  each program the department teaches. The page table changes yearly.
- [ ] **Admission scores** (`abiturient.spbu.ru/medialibrary/...`) — PDFs
  with individual achievements, olympiad benefits, and scoring criteria.
- [ ] **Tuition fees** — costs per program on `abiturient.spbu.ru`.
- [ ] **Application instructions** — Gosuslugi link, deadlines, required
  documents on `bachelor_application.html`.

## Living costs & scholarships

- [ ] **Dormitory prices** — links to `students.spbu.ru` accommodation page.
- [ ] **Scholarship info** — `students_scholarships.html` and all 13
  scholarship sub-pages. Amounts, application deadlines, PGAS process.
- [ ] **External scholarship programs** — `fasie.ru`, `alfabank.ru`,
  `fondpotanin.ru`, `euler-foundation.org` — still exist and accept
  applications.

## External references

- [ ] **SimpleMDE / markdown-guide** — `markdownguide.org` link still valid.
- [ ] **Telegram, VK contacts** — still the right people.
- [ ] **All SPbU subdomains** — `students.spbu.ru`, `my.spbu.ru`,
  `guestbook.spbu.ru`, `abiturient.spbu.ru` — URLs still resolve.

## Prices & figures

- [ ] **Bachelor admission page** tuition figures match reality.
- [ ] **Master admission page** tuition figures.
- [ ] **Dormitory cost** listed in FAQ and bachelor_admission.
- [ ] **Scholarship amounts** (standard, social, повышенная).

## Not a closed list

If you found something outdated that is not on this list, add it. The goal
is zero broken links and zero stale figures during the admission period.
