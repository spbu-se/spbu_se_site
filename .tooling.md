## Git & GitHub CLI

### `git commit` hangs on Windows

If GPG is configured (`user.signingkey`) but KeePass/password storage is locked, `git commit` waits indefinitely for unlock. Use `--no-gpg-sign` for staging/feature commits. Only merge commits to `current` need signoff.

## Hook design reasoning

Three-tier quality model installed in this repo:

- **Pre-commit**: convenience polish on changed files only. May be skipped with `--no-verify`.
- **Pre-push**: strict full-repo gate. Fail-fast chain: format → mypy → pytest.
- **Staging merge**: pre-push is the minimum bar. No branch should reach staging without passing.

This design exists because the agent repeatedly skipped fast checks to save seconds, costing minutes in CI round-trips. Documented in session 5 retro (2026-07-08).
