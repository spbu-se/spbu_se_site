# Local Tooling Quirks

<!-- encoding: utf-8 -->

Only local host / environment workarounds. Not project design decisions.

## UTF-8 BOM in requirements.txt

PowerShell `>` and `Set-Content -Encoding utf8` both write UTF-8 BOM (EF BB BF).
Linux CI (`pip install -r`) fails to parse the file.

**Always use:**

```powershell
[System.IO.File]::WriteAllText("requirements.txt", $(uv export --no-dev --no-hashes), [System.Text.UTF8Encoding]::new($false))
```

## PowerShell 5.1

### `&&` / `||` not available

```powershell
# Wrong:
cmd1 && cmd2

# Correct:
cmd1; if ($?) { cmd2 }
```

### No `grep`

Use `Select-String` instead.

### `curl` is an alias

`curl` maps to `Invoke-WebRequest`, not the real `curl`. Use `curl.exe` for actual HTTP requests.

### `||` not available

```powershell
# Wrong:
cmd1 || cmd2

# Correct:
cmd1; if (-not $?) { cmd2 }
```

### Inline Python quoting

`-c "..."` uses PowerShell string rules (double quotes interpolate `$`). Escape `$` with backtick or use single quotes on the outside:

```powershell
uv run python -c 'import os; print(os.name)'
```

## uv on Windows

`uv lock` resolves for ALL platforms, including Windows. If a dep can't build on Windows (source-only, Unix-only), `uv lock` fails even with platform markers. **Remove such deps from pyproject.toml entirely.**

## Git & GitHub CLI

### `git commit` hangs on Windows

If GPG is configured (`user.signingkey`) but KeePass/password storage is locked, `git commit` waits indefinitely for unlock. Use `--no-gpg-sign` for staging/feature commits. Only merge commits to `current` need signoff.

### `gh run watch` times out

`gh run watch` exits after ~5 minutes even if CI is still running. Use non-blocking polling:

```powershell
gh run list --branch staging --workflow "CI (staging)" --limit 1 --json conclusion
```

### Target a specific workflow

`gh run list` by default shows all workflows. Filter with `--workflow "CI (staging)"` to get only the relevant status.

### Rate limits

Rapid `gh run list` calls may hit GitHub API rate limits. Space polling calls 10-15 seconds apart.
